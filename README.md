# nutri-grant-proposal · 临床营养类科研基金申报书写作 Skill

一个写给 AI 用的"标书写作手册"，把一份真实立项的临床营养基金申报书（云南省营养学会科研基金—西安力邦临床营养专项基金·青年项目）的写法拆解成可复用的骨架、句式与自检规则。

## 适用场景

- 撰写/改写学会基金、专项基金、青年或基层项目申报书
- 临床营养、膳食调查、文献计量方向的标书
- 已有初稿的章节补写、口径统一、预算配平、格式排版

## 内容结构

```
nutri-grant-proposal/
├── SKILL.md                        # 主文件：12 节骨架 + 写法公式 + 预算配平恒等式 + 去 AI 味规则
├── references/
│   ├── writing-playbook.md         # 各节细则：摘要四段式、样本量测算、亚组门槛、句式模板
│   └── docx-format.md              # 表格型申报书的 python-docx 操作要点与坑
└── scripts/
    └── audit_proposal.py           # 提交前自检：金额配平 + 字体审计 + 错别字/口径雷区
```

## 安装

复制整个目录到 WorkBuddy 的用户级技能目录：

```bash
cp -r nutri-grant-proposal ~/.workbuddy/skills/
```

之后在对话中说到"写标书/写基金/立论依据/研究计划/经费预算"等即可触发。

## 自检脚本

```bash
python3 scripts/audit_proposal.py 申报书.docx
```

输出三类检查：

1. **金额配平**：分项之和 = 一、经费支出 = 二、经费来源 = 经费合计 = 申请资金 = 封面申请金额 = 信息表申请金额
2. **字体审计**：中文字体是否收敛到宋体/黑体，字号分布（half-points）
3. **错别字与口径**：`FQQ→FFQ`、金额未写两位小数、漏字、叠词、"逐篇/逐条"、阶段数冲突

存在 ❌ 级问题时退出码为 1，可直接用于提交前门禁。

实测样例（某定稿）：

```
== 金额配平 ==
❌ 金额不一致：一、经费支出=1.2，封面/主口径=2.0
== 错别字与口径 ==
⚠️ FFQ 误写为 FQQ: …制做本土化FQQ问卷…
⚠️ 误植字母“多民族t门诊”…
```

## 核心提醒

- 先取原稿再动笔，别凭记忆重写章节。
- 改总额必须同步 6 处并重新配平分项。
- 阶段数、样本量、关键词在中英文摘要与正文中必须逐处对齐。
- 拒绝"AI 味"：不用彩色圆角图形、排比堆砌与"赋能/闭环/抓手"。
